Расчёт метрик Джилба

В абсолютную сложность CL входят операторы, проверяющие условие: if, else if, for, while, do (цикл do…while один раз), каждая метка case. Не увеличивают CL: else, default, само ключевое слово switch. Без default считаются все case (формула методички n − 1 — только для switch с default).

Относительная сложность cl = CL / Nop, где Nop — операторы языка в классическом виде: заголовки if/for/while/do/switch и инструкции с ; (включая break/return). Без объявлений, без else/case/default как отдельных операторов и без пунктуации Холстеда. Слово switch входит в Nop, но не в CL.

CLI — максимальная глубина вложенности: for с if внутри → 1; ветки case считаются как цепочка IF (глубина = база + номер ветки − 1), поэтому switch с n ветвями и default даёт CLI = n − 2.
